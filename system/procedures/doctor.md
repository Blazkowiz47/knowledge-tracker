# Procedure: Knowledge-Base Doctor

The default audit is read-only. Change files only for an explicit `/doctor fix` request.

Check:

1. Git branch/upstream, unrelated changes, and stale automation locks.
2. Registry YAML, one coordinator, canonical nodes/aliases, and project paths keyed by known nodes.
3. Ledger/staging node identity and suspicious topic-like filename suffixes.
4. Registry/index/folder agreement, five-file workstream layout, valid states, Context Cards, and `last_activity`.
5. Portfolio focus limits, actionable `now`/`next`, explicit `waiting`, and archived placement.
6. Daily-brief freshness, log indexes, active summaries, and no-op telemetry noise.
7. Ledger/queue validity, unique identities, hashes, staging coverage, status freshness, and failures.
8. Template and public-skill agreement, Claude imports, stale command links, and portable paths.
9. Broken Markdown links, malformed frontmatter, placeholder bullets, and oversized overview pages.

Group output into Needs attention, Recommended cleanup, and Healthy. Name the file and smallest safe correction. In fix mode, preview destructive/ambiguous changes, preserve unrelated work, validate again, then commit/push.
