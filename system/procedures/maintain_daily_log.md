# Procedure: Maintain Human Logs

Follow this procedure before writing human-facing knowledge-base logs.

For read-only startup, read `wiki/logs/index.md` and open detail only as needed. Do not create today's log merely because a session or read-only command ran.

Before a meaningful entry:

1. Resolve the date.
2. Create `wiki/logs/YYYY/MM/DD.md` with Summary/Entries only if needed.
3. Ensure the month index has a newest-first row and active month/year summaries exist.
4. Append a compact entry for meaningful synthesis, decisions, commitments, curation, structural changes, or failures requiring attention.

Successful no-op syncs update node-owned and coordinator operational status instead of human logs.

Finalize older `Pending` summaries during `/day close`, explicit summarization, or meaningful rollover. Do not create missing empty days merely for calendar continuity. Keep `wiki/log.md` as a compatibility pointer.
