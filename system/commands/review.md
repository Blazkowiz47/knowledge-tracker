# Command: /review

Review portfolio focus and workstream lifecycle state.

1. Accept an optional workstream scope or `report-only` request.
2. Follow `system/procedures/review_portfolio.md`.
3. Keep at most three workstreams in `now` unless the user explicitly chooses otherwise.
4. Rebuild the compact portfolio index and daily brief after state changes.
5. Commit and push knowledge-base edits only.
