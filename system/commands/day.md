# Command: /day

Manage the generated daily brief and end-of-day knowledge cleanup.

- `/day start`: regenerate `wiki/today.md` from portfolio, inbox, pending, and sync state.
- `/day close`: organize the inbox, finalize meaningful synthesis, promote durable outcomes, and carry unfinished work forward deliberately.

Follow `system/procedures/manage_day.md`. Do not create human log entries for a view-only refresh or no-op sync. Commit and push only when files changed.
