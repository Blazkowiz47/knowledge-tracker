# Command: /initialise-project

Initialize project-local memory and register its workstream.

1. Require a target project path; accept optional name, domain, tags, slug, node, and seed context.
2. Follow `system/procedures/maintain_daily_log.md` before writing an initialization record.
3. Follow `system/procedures/initialise_project.md`.
4. Register node/path identity under `system/registry/`.
5. Leave the target project unstaged, uncommitted, and unpushed.
6. Commit and push knowledge-base changes only.
