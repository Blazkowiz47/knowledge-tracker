# Command: /plan-tomorrow

Internal compatibility primitive. Prefer `/day close` to carry unfinished work forward and prepare tomorrow.

Create or update the next-day plan from synced memory.

## Steps

1. Follow `system/procedures/maintain_daily_log.md`.
2. Follow `system/procedures/plan_tomorrow.md`.
3. Use `wiki/logs/index.md`, `wiki/today.md`, and relevant workstream context.
4. Append the planning detail to today's knowledge-base daily log if files changed.
5. Commit and push knowledge-base changes only.
