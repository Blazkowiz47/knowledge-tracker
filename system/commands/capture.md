# Command: /capture

Capture and route knowledge without requiring separate log, learning, decision, run, status, or scratch commands.

1. Require content; accept optional workstream, kind, date, node, evidence, or destination.
2. Follow `system/procedures/capture.md`.
3. Infer routing only when clear; route ambiguity to `wiki/scratch/`.
4. Keep external projects read-only unless the user explicitly authorizes a named project-memory write.
5. Commit and push knowledge-base changes according to `AGENTS.md`.

Report the destination and any uncertainty.
