# Scratch

Knowledge-base inbox for uncertain captures. `/capture` routes clear material directly and places ambiguous material here.

## Rules

- Use one file per capture; `README.md` is never swept.
- Prefer compact frontmatter with capture time, optional workstream, kind, and `status: inbox`.
- Files may be routed or deleted during `/day close`.
- Project-only working documents ultimately belong in project `memory/scratch/`, but the knowledge-base router does not edit external project memory without explicit authorization.

## End Of Day

Run `/day close`. It can route captures into workstream Active Threads, logs, learnings, decisions, runs, status, or human daily logs; delete ephemeral items; or leave an item with a proposed project-memory destination.
